## Summary

Both findings are closed as specified:

- **Finding #2** (`manifest_builders_exact` was a census-label tautology):
  `Entry.builder` (a bare string-or-callable-or-None) is replaced by typed
  `CallableProof`/`HarnessProof` objects; the `'harness'` string fallback is
  gone; a `built` census record with no valid proof is now a hard
  `RuntimeError` at manifest-generation time, not a silent pass; `exact` is
  now tied to live `bad==0` gate state per metric, not `is not None`.
- **Finding #3** (fork ownership was prose, not validated): the census is
  now fork-granular (`docs/disk_census_2026-08-01.json`, machine-migrated by
  the checked-in, re-runnable `work/census_migrate.py`); `manifestcheck.py`
  validates `(path, fork)` keys both directions including HFS resource
  forks (previously ignored entirely); Disk 7's six data-fork targets no
  longer implicitly claim their resource forks are built.

`manifest_builders_exact` moved from a hardcoded-equal-to-`wired` tautology
to a metric that is *currently* equal to `wired` because every proof
reachable today happens to be exact — but the two are now structurally
independent, and the machinery will show a real gap the moment any BUILT
fork's backing harness metric regresses, without this file needing to
change.
